🔭 Motivation

The ALMA Science Archive contains petabytes of data spanning a decade of observations. Despite rich programmatic interfaces, translating a research question into the right combination of archive queries, metadata filters, and analysis steps requires substantial domain knowledge in radio interferometry — a significant barrier for students and interdisciplinary researchers.

Key Insight

A general-purpose LLM becomes a capable scientific assistant not through model fine-tuning alone, but in combination with careful domain engineering.

🟢 Case Study 1: Direct Archive Search
"Find ALMA observations of M87 in Band 6."
1
Complexity Detection → Simple
Heuristic scan classifies as simple; routed to Agent Tool Loop.
2
Tool Invocation
LLM calls search_by_target(target: M87, band: 6), translating natural language to ADQL.
3
Automatic Fallback
If name resolution fails → resolves via SIMBAD → re-issues as cone search.
🟠 Case Study 2: Orchestration + Sandboxing
"Check CO(2-1) line coverage for M87."
1
Archive Agent
Retrieves all Band 6 observations for M87 and extracts spectral window limits.
2
Analysis Agent + REPL
Calculates redshifted CO(2-1) frequency (νrest ≈ 230.538 GHz) via Sandboxed Python and cross-matches against spectral ranges.
3
Synthesis + Notebook
Aggregates matching projects into Markdown summary + reproducible Jupyter Notebook.
📖 Case Study 3: Literature Extraction
"Find the 2018 DSHARP survey paper by Andrews et al. and extract the angular resolution for AS 209."
1
Literature Agent
Uses NASA ADS tool suite to identify the correct bibcode and retrieve the paper's full text.
2
Grounded Extraction
Accurately extracts synthesized beam parameters — no hallucination from pre-training weights.
🚀 Conclusion & Future Work

Quasar synthesizes domain-specific tool use with robust task planning to make astronomical data retrieval and analysis accessible through natural language.

  • Multi-LLM consensus protocols for the Conductor to reduce single-point-of-failure risk
  • Open-weight LLM migration for local deployment without proprietary dependencies
  • Quantitative benchmarks with structured evaluation suite
  • Multi-wavelength expansion to NRAO, MAST, NOIRLab, and Astro Data Lab archives
