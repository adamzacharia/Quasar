5.3.2 Data using band-to-band (B2B) phase referencing for calibration
Some observations, particularly high frequency observations, will use a technique called band-to-band (B2B)
phase referencing to improve the calibration of the data. These observations will typically include not only a
bandpass/amplitude calibration source and a phase calibration source but also a third calibration source for
phase referencing. The phase calibrator would be observed in a lower frequency band than the science target,
and then the phase calibration tables from those data would be applied to higher frequencies using the phase
gain offset derived from the phase referencing source data acquired in both the lower and higher frequency bands.

5.3.1 7-m Array data using TP antennas for calibration
It has been common policy for ACA observations in Bands 8, 9, and 10 to include the TP antennas as part of
the array. Such a configuration can be identified when viewing the antenna setup on the overview page for an
individual EB. In terms of the output from the tasks that appears in the WebLogs, this produces a few changes
from standard WebLogs for ACA data. In particular, the TP antennas may use different spectral windows with
slightly different spectral setups from the ACA antennas, andhifa_wvrgcalflag will be executed for the data
from the TP antennas. However, most other data from arrays using this configuration are otherwise similar to
what is produced from normal ACA observations.
