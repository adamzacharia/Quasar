## Web search pipeline flags (web search redesign, 2026-09)

The `web_*` tools above and the parallel pre-pass search share one evidence pipeline. Every
flag defaults ON; `0` restores the previous phase's behaviour. Values are read per turn.

| Flag | Default | Phase | Effect |
|---|---|---|---|
| `QUASAR_WEB_GROUNDED` | 1 | 1 | Web results become numbered evidence W1..Wn the model sees before writing and cites inline as `[W#]`; 0 = the legacy appended "From the Web" paragraph |
| `QUASAR_WEB_DEEP_READ` / `QUASAR_WEB_DEEP_READ_BUDGET` | 1 / 5 s | 1 | Tavily Extract on the top 3 pages (query-focused chunks) within the budget |
| `QUASAR_WEB_EVIDENCE_WAIT` | 8 s | 1 | Max wait from the pre-pass start before the answer is generated |
| `QUASAR_LLM_CUTOFF` | 2025-06 | 0 | Chat models' training cutoff (YYYY-MM) |
| `QUASAR_WEB_PLANNER` | 1 | 2 | One strict-JSON planner call (`core/web_planner.py`) decides the undecided case, resolves follow-ups from the last 3 turns, rewrites 1 to 3 queries, picks a domain pack and freshness; fails closed to the deterministic path; also enables the D15 researcher check, domain packs, authority ordering, the `web_decision` event and the per-query status steps |
| `QUASAR_WEB_PLANNER_MODEL` / `QUASAR_WEB_INTENT_MODEL` | gpt-oss-120b | 2 | Models for the planner and the legacy YES/NO decision (not `QUASAR_FAST_MODEL`) |
| `QUASAR_WEB_PLANNER_TIMEOUT` | 5 s | 2 | Wall clock for the planner call (credited to the evidence wait) |
| `QUASAR_WEB_SEARCH_BUDGET` | 6 s | 2 | Join budget for the parallel pack-restricted + unrestricted searches (`services/web_domain_packs.py`) |
| `QUASAR_WEB_CARRY_EVIDENCE` | 1 | 2 | A follow-up turn re-registers the previous turn's cited pages with new ids |
| `QUASAR_WEB_REVISE` / `QUASAR_WEB_REVISE_BUDGET` | 1 / 6 s | 2 | One bounded rewrite of cited sentences whose numbers or dates the source does not show (`core/web_revise.py`); the check runs again afterwards |

Request field `web_search_mode` (`off` / `auto` / `always`) on `/api/chat` and `/api/chat/upload`
wins over the boolean `web_search` (true = auto, false = off). SSE event `web_decision`
(one per turn) carries mode, need_web, reason, queries, planner time, domain pack and
freshness; it is persisted as `rich_meta.webDecision`. The tool trace gets a
`web_citation_check` record per grounded answer with the unsupported-claim counts before and
after the revise pass.
