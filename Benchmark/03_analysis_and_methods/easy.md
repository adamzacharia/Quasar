**Question:**
> Is there a way to make a query of the ALMA Science Archive to retrieve ALMA data for a specific object through Python?

**Skills Tested:**
- Knowledge of programmatic access methods for the ALMA archive
- Awareness of Python libraries (Astroquery, ALMiner, TAP+ via pyvo)
- Ability to provide working code examples

**Expected Tools:**
- RAG pipeline (documentation retrieval)
- Possibly code generation

**Evaluation Criteria:**
- [ ] Confirms that yes, Python-based query is possible
- [ ] Mentions at least one method: **Astroquery** (`astroquery.alma`)
- [ ] Optionally mentions **ALMiner**, **pyvo** (TAP), or direct HTTP/API access
- [ ] Provides a working code snippet demonstrating the query
- [ ] Code example is syntactically correct and runnable
- [ ] Explains what the code does
