## SQ-E-01: Protostellar Outflows Publications

**Question:**
> I'm interested in studying protostellar outflows. Please make a table of the 10 most recent publications on this topic that used data from the ALMA Science Archive, and summarize them. Use the ALMA Science Archive to get this information.

**Skills Tested:**
- Querying the ALMA Science Archive for bibliographic / publication data
- Understanding the link between ALMA data and publications (via telbib or ADS)
- Table generation and summarization
- Knowledge of how to access ALMA-related publications

**Expected Tools:**
- ALMA Science Archive publication search
- ADS (Astrophysics Data System) query if needed
- RAG pipeline for methodology
- Table formatting

**Evaluation Criteria:**
- [ ] Retrieves publications linked to ALMA data on the topic of protostellar outflows
- [ ] Presents at least 10 publications (or all available if fewer)
- [ ] Each entry includes: **Title**, **Authors**, **Year**, **Journal**, **ALMA Project Code** (if available)
- [ ] Provides a brief summary of each publication's key findings
- [ ] Publications are sorted by recency (most recent first)
- [ ] Uses an appropriate data source (ALMA telbib, ADS, or archive bibliography)
- [ ] Output is well-formatted as a table
